# Shadowrocket for Android

**Современный VPN-клиент для Android с управлением proxy, тестами узлов, маршрутизацией, резервным копированием и диагностикой сети.**

## Скачать APK

Выберите APK под архитектуру процессора устройства. Если не уверены, сначала скачайте arm64-v8a。

APK-файлы на GitHub доступны на странице [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Возможности

Поддерживает импорт, отправку и резервное копирование proxy-профилей, подключение одним нажатием, тест задержки и диагностику узлов.
