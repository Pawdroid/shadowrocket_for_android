## Scarica APK

Scegli l’APK adatto all’architettura CPU del dispositivo. Se non sai quale scegliere, prova prima arm64-v8a.

I file APK su GitHub sono disponibili nella pagina [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Funzioni principali

Supporta importazione, condivisione e backup dei profili proxy, connessione con un tocco, test di latenza e diagnosi dei nodi via browser.
