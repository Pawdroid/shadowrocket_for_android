## Pobierz APK

Wybierz APK zgodny z architekturą CPU urządzenia. Jeśli nie wiesz, wybierz najpierw arm64-v8a。

Pliki APK w serwisie GitHub są dostępne na stronie [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Najważniejsze funkcje

Obsługuje import, udostępnianie i backup profili proxy, połączenie jednym dotknięciem, test opóźnienia i diagnostykę węzłów.
