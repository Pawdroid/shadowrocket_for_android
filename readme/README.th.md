# Shadowrocket for Android

**ไคลเอนต์ VPN สมัยใหม่สำหรับ Android พร้อมการจัดการพร็อกซี ทดสอบโหนด การกำหนดเส้นทาง สำรอง และการวินิจฉัยเครือข่าย.**

## ดาวน์โหลด APK

เลือก APK ให้ตรงกับสถาปัตยกรรม CPU ของอุปกรณ์ หากไม่แน่ใจ ให้เลือก arm64-v8a ก่อน。

ดูไฟล์ APK บน GitHub ได้ที่หน้า [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest)

## คุณสมบัติเด่น

รองรับการนำเข้า แชร์ และสำรองโปรไฟล์พร็อกซี, การเชื่อมต่อด้วยการแตะครั้งเดียว, การทดสอบความหน่วง, และการวินิจฉัยโหนดผ่านเบราว์เซอร์.
