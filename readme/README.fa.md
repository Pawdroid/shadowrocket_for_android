# Shadowrocket for Android

**کلاینت VPN مدرن برای Android با مدیریت پراکسی، تست نود، مسیریابی، پشتیبان‌گیری و عیب‌یابی شبکه.**

## دانلود APK

APK متناسب با معماری دستگاه را انتخاب کنید. اگر مطمئن نیستید، ابتدا arm64-v8a را بگیرید.

بسته‌های APK گیت‌هاب در صفحهٔ [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) در دسترس هستند.

## ویژگی‌ها

از وارد کردن، اشتراک‌گذاری و پشتیبان‌گیری پروفایل پراکسی، اتصال یک‌لمسی، تست تأخیر، عیب‌یابی نود با مرورگر و پیشنهادات DNS/FakeDNS پشتیبانی می‌کند.

## نصب

APK را از GitHub Releases دانلود کرده و روی دستگاه باز کنید. در صورت مسدود شدن، امکان نصب از مرورگر یا فایل‌منیجر را فعال کنید.
