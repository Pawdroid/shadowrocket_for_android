# Shadowrocket for Android

**Σύγχρονος πελάτης VPN για Android με διαχείριση proxy, έλεγχο κόμβων, δρομολόγηση, αντίγραφα ασφαλείας και διάγνωση δικτύου.**

## Λήψη APK

Επιλέξτε APK που ταιριάζει στην αρχιτεκτονική CPU της συσκευής. Αν δεν είστε σίγουροι, επιλέξτε πρώτα arm64-v8a.

Τα αρχεία APK του GitHub διατίθενται στη σελίδα [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).
