## APK をダウンロード

端末の CPU アーキテクチャに合う APK を選んでください。不明な場合は、まず arm64-v8a を選択してください。

GitHub の APK は [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) ページでご確認ください。

## 主な機能

プロキシプロファイルのインポート、共有、バックアップ、ワンタップ接続、遅延テスト、ノード診断をサポートします。
