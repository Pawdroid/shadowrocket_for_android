## Ladda ned APK

Välj APK som matchar enhetens CPU-arkitektur. Om du är osäker, välj arm64-v8a först。

APK-filerna på GitHub finns på sidan [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Höjdpunkter

Stöder import, delning och backup av proxyprofiler, ett-trycksanslutning, latenstest och browserbaserad noddiagnos.
