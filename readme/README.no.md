## Last ned APK

Velg APK-en som passer enhetens CPU-arkitektur. Hvis du er usikker, velg arm64-v8a først。

APK-filene på GitHub finnes på siden [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Høydepunkter

Støtter import, deling og sikkerhetskopi av proxyprofiler, ett-trykks tilkobling, latenstest og browserbasert nodediagnose.
