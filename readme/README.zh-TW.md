**適用於 Android 的現代 VPN 用戶端，支援代理設定管理、節點測速、路由工具、備份與網路診斷。**

## 下載 APK

請選擇符合裝置 CPU 架構的 APK。如果不確定，建議優先下載 arm64-v8a。

GitHub 安裝包以 [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) 頁面為準。

## 功能亮點

- 代理設定管理，支援匯入、分享與備份。
- 一鍵連線與節點延遲測試。
