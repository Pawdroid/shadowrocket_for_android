## Baixar APK

Escolha o APK compatível com a arquitetura do seu dispositivo. Se não tiver certeza, baixe primeiro arm64-v8a。

Os arquivos APK do GitHub estão disponíveis na página [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Recursos

Inclui importação, compartilhamento e backup de perfis proxy, conexão com um toque, teste de latência e diagnóstico de nós.
