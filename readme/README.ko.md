# Shadowrocket for Android

**Android용 최신 VPN 클라이언트로 프록시 관리, 노드 테스트, 라우팅, 백업, 네트워크 진단을 지원합니다.**

## APK 다운로드

기기 CPU 아키텍처에 맞는 APK를 선택하세요. 잘 모르겠다면 arm64-v8a를 먼저 선택하세요。

GitHub APK는 [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) 페이지에서 확인하세요.

## 주요 기능

프록시 프로필 가져오기, 공유, 백업, 원터치 연결, 지연 시간 테스트 및 노드 진단을 지원합니다。
