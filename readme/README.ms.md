## Muat turun APK

Pilih APK yang sepadan dengan seni bina CPU peranti anda. Jika tidak pasti, pilih arm64-v8a dahulu。

Fail APK di GitHub tersedia pada halaman [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Ciri utama

Menyokong import, perkongsian dan sandaran profil proksi, sambungan sekali ketik, ujian latensi dan diagnosis nod.
