## APK letöltése

Válaszd a készülék CPU-architektúrájának megfelelő APK-t. Ha bizonytalan vagy, először az arm64-v8a fájlt töltsd le.

A GitHubon elérhető APK-fájlok a [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) oldalon találhatók.

## Fő funkciók

Támogatja a proxyprofilok importját, megosztását és mentését, az egyérintéses kapcsolatot, késleltetéstesztet és böngészőalapú csomópont-diagnosztikát.
