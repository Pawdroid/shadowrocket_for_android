# Shadowrocket for Android

**Modernong VPN client para sa Android na may proxy management, node testing, routing, backup, at network diagnosis.**

[← All languages](../README.md) · [Dokumentasyon](https://docs.shadowrockets.app)

## I-download ang APK

Piliin ang APK na tugma sa CPU architecture ng device. Kung hindi sigurado, piliin muna ang arm64-v8a.

Makikita ang mga APK sa GitHub sa pahina ng [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Mga tampok

May import, share at backup ng proxy profiles, one-tap connection, latency test, browser-based node diagnosis at WebDAV backup support.
