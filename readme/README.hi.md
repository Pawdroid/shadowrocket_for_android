## APK डाउनलोड करें

अपने device की CPU architecture के अनुसार APK चुनें। अगर निश्चित नहीं हैं, पहले arm64-v8a चुनें।

GitHub के APK डाउनलोड [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest) पेज पर उपलब्ध हैं।

## मुख्य सुविधाएँ

Proxy profile import, share और backup, one-tap connection, latency test, browser-based node diagnosis और WebDAV backup सहायता।
