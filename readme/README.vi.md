## Tải APK

Chọn APK phù hợp với kiến trúc CPU của thiết bị. Nếu không chắc, hãy tải arm64-v8a trước。

Các tệp APK trên GitHub có trên trang [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Tính năng nổi bật

Hỗ trợ nhập, chia sẻ và sao lưu hồ sơ proxy, kết nối một chạm, kiểm tra độ trễ và chẩn đoán node.
