## Télécharger l’APK

Choisissez l’APK correspondant à l’architecture de votre appareil. En cas de doute, prenez arm64-v8a.

Les fichiers APK de GitHub sont disponibles sur la page [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## Fonctions principales

Prend en charge l’importation, le partage et la sauvegarde des profils proxy, la connexion en un geste, les tests de latence et le diagnostic de nœud via le navigateur.
