## הורדת APK

בחר את קובץ ה-APK שמתאים לארכיטקטורת המכשיר. אם אינך בטוח, בחר קודם arm64-v8a.

קובצי ה-APK ב-GitHub זמינים בדף [GitHub Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases/latest).

## תכונות

תומך בייבוא, שיתוף וגיבוי של פרופילי פרוקסי, חיבור בלחיצה אחת, בדיקות השהיה, ואבחון צמתים.
